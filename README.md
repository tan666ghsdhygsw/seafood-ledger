# 海鲜记账（手机网页版 v3.5）

晚上把本子上的账搬进手机，出总账、出欠账、出每个客户的数。

**设计前提**：她一个人点，不打字；每笔两三个动作。

---

## 一、这一版改了什么

### v3.5

| 改动 | 说明 |
|---|---|
| **卖货：价格变成一个一个的钮** | 进到某一档，顶上是一排价：`[50元] [45元] ＋加一个价`。点哪个，下面填的人就按哪个算 |
| 降价了就再加一个价 | 50 那批填完 → 加一个 45 → 自动切到 45 → 接着填。已经填好的不会变 |
| 加货类不用选分法了 | 加完就有四个分法（不分 / 分大小 / 分有膏 / 都分），进去再选 |
| 进场费回到一个数 | 支出页一个格子填当天总数，不用按次加 |
| **点按有回弹** | 所有按钮按下会缩一下，换页有淡入，不再是硬切 |

### v3.4

| 改动 | 说明 |
|---|---|
| **删掉场次** | 早市/午市/晚市整套去掉 |
| **卖货改成点名单** | 进到某一档，直接把客户列出来，一行一个人，右边填斤数 |
| **全局撤回** | 右上角 ↩，每一步都能退回去 |

### v3.3

| 改动 | 说明 |
|---|---|
| 输入不再被挡 | 键盘弹起时底部导航自动收起，不再压住输入框 |
| 收货不用点按钮 | 填完斤数（价可不填），点别处／切页签就**自动记下** |
| 货类按钮放大 | 选货的按钮大了一圈 |
| 名单拆两套 | **收货的人**（档口）和**买货的人**（客户）分开，互不干扰 |
| 名单排版变紧 | 一人一行改成小格子，一屏能看十几个，字没变小 |
| 对账一键结清 | 每个客户一个「✓ 全结清」，明细里每一笔也有「✓」 |
| 欠款更醒目 | "别人欠我的／我欠档口的"字号放大 |
| 颜色修正 | 别人欠我的→**红**；我欠档口的→**绿** |

### v3.2

| 改动 | 说明 |
|---|---|
| 品种顺序 | **虾姑排第一**，后面是大长劲、三点蟹、花蟹、冬蟹、石头蟹 |
| 改名 | **硬壳 = 虾姑**；大长劲还是叫"大长劲"，两个分开算 |
| 收货价 | **可以空着不填**，卖完跟档口定好价再回来补（标"待定价"） |

## 二、今晚第一次用，先做两件事

1. 打开网址（电脑 `http://127.0.0.1:8899/`，手机 `http://电脑IP:8899/`）
2. 右上角 ⚙ → **收货的人**、**买货的人** 两份名单分别粘进去，保存
   ```
   志浩
   阿明
   林浩
   卢妹(虾古、蚧)
   周姐(虾古亚周)
   ```
   工人名单也在这儿填。**只填这一次。**

## 三、晚上怎么走

```
① 今天拉几趟货进市场？ [1] [2] [3]
② 填这场进场费
③ 收 货（一天就一次，不分场次）
④ 卖 货 / 清 货 / 损 耗（按当前场次）
⑤ 收工，出今天的账 → 自动备份
```

### 收货
点「收货」→ 点档口 → 点货 → 点档位 → 填斤数 → **单价可以先空着**。

> 空着记下来之后，记录上会标「待定价」。等卖完跟档口定好价，去「对账」页最上面，一条一条点「定价」补上。

### 卖货
点「卖货」→ 点货 → 分法开关（不分/分公母/分大小/都分）→ 点档位 →

```
┌ 50 元/斤 ───────┐ ┌ 45 元/斤 ──────┐
│ 林浩      20 斤  │ │ 谭明     30 斤  │
│ ＋ 加一人        │ │ ＋ 加一人       │
└─────────────────┘ └────────────────┘
         ＋ 加一个价
```

**一笔记卖货 = 点人 + 填斤数。**

### 进场费
首页场次标签下面直接填，每场一个数。支出页能看各场汇总。

## 四、对账

- **最上面：还没定收货价的**（黄色），点「定价」补单价
- **今天还没给钱的**：每个客户一张卡，可直接复制发微信（多行版 / 简短版）
- 抹零留痕：`5.5斤*11=60.5→60`
- **结了多少** → 填金额 → 自动算还欠多少，可以分几次结
- 还欠着的（跨天）、我还没付档口的

---

## 五、汇总

```
收进来  ¥6,830     ← 红字
花出去  ¥5,896     ← 绿字
今天到手 +¥934     ← 红（赚）
```

下面：收了什么/卖了多少斤（按品种，含差额校验）、钱从谁那来（红）、钱付给了谁（绿）。

**点「收工」自动导出一份备份**到手机"下载"文件夹。

## 六、品种表

| 品种 | 分法 |
|---|---|
| **虾姑**（原硬壳） | 不分 / 分有膏 / 分大小 / 都分 |
| 大长劲 | 同上 |
| 三点蟹 | 不分 / 大 / 中 / 小 |
| 花蟹 | 不分 / 分公母 / 分大小 / 都分（6 格） |
| 冬蟹 | 肥蟹 / 水蟹 |
| 石头蟹 | 不分 |

---

## 七、规则

| 项 | 规则 |
|---|---|
| 营业日 | 凌晨 6 点前算前一天 |
| 场次 | 1–3 场，早市 / 晚市（3 场时含午市），按"拉几趟货"算 |
| 收货 | 一天一次，不挂场次 |
| 单位 | 斤，支持小数 |
| 人 | 档口和客户共用一套名单 |
| 数据 | 本地存储，关掉再开都在 |

## 九、安卓 App 版

见 **[打包说明.md](打包说明.md)**。

要点：

- 桌面图标叫「海鲜账」，点开直接是记账页，**完全离线**
- 数据存在 App 自己那里，和网页版**不互通**
- 「收工」时备份自动存到手机 **下载** 文件夹
- 实体返回键：先关弹层 → 再退一屏 → 退无可退才退出
- 要 Android 8.0 以上
